# Website

Personal website/blog of Jorgen Bergstrom, PhD — about polymer mechanics and
machine learning. A Hugo static site deployed to GitHub Pages at
https://bergstrom.org/.

## Contents

| File/Dir | Description |
|---|---|
| `hugo.yaml` | Main site configuration |
| `content/posts/` | Blog articles (flat structure) |
| `layouts/partials/` | Theme overrides |
| `static/` | Images, videos, CNAME, favicons |
| `themes/LoveIt` | LoveIt theme (git submodule) |
| `themes/PaperMod` | PaperMod theme (git submodule, unused) |
| `public/` | Build output (gitignored) |
| `.github/workflows/hugo.yaml` | CI: build + deploy + Bluesky announce |
| `scripts/post-to-bluesky.sh` | Bluesky announcement script |
| `README.md` | Project documentation |
| `AGENTS.md` | Agent hand-off notes |

See **AGENTS.md** for detailed documentation on stack, deployment, content
authoring conventions, and common tasks.
